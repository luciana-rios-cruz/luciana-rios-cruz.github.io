Sign Classification with Deep Learning

Individual Academic Project | Tecnológico de Monterrey | March–May 2026

Image classification of hand signs representing letters A–D using MATLAB and AlexNet transfer learning.

PROJECT OVERVIEW

Developed a four-class image classifier to recognize hand signs corresponding to A, B, C, and D. Adapted a pretrained AlexNet network, trained it on a custom dataset, and evaluated predictions on new images.

THE ENGINEERING CHALLENGE

Distinguish visually similar hand configurations using a limited dataset of approximately 10 original images per class. The project explored transfer learning and data augmentation to support classification with limited training data.

DATASET & AUGMENTATION

Organized approximately 40 original images into four labeled folders. Applied rotation, scaling, and translation to introduce variations during training and improve generalization.

NETWORK ARCHITECTURE — ALEXNET

Used pretrained AlexNet as the starting point, replacing its final fully connected and classification layers for four output classes. Test images were resized to 227 × 227 pixels to match the network input.

CLASSIFICATION WORKFLOW

Load: Import the trained network from miRed_ABCD.mat.

Preprocess: Read and resize a new image.

Classify: Predict the letter using MATLAB’s classify function.

Analyze: Display the predicted class and its confidence score.

Visualize: Plot scores across all four classes to examine uncertainty.

TESTING & RESULTS

The model recognized examples from all four classes, with varying confidence. Reported scores for the illustrated test images were:

A: 43.28%

B: 68.97%

C: 44.45%

D: 46.76%

The B example received the highest confidence. Similar scores across competing classes revealed uncertainty in some predictions. These values describe individual test predictions, rather than overall classification accuracy.

LIMITATIONS & NEXT STEPS

The small dataset limited the variety of hand positions and imaging conditions available for training. Further development would include more examples, varied lighting and backgrounds, and a larger labeled test set to measure classification accuracy.

MY CONTRIBUTION

I prepared the dataset, adapted AlexNet’s final layers, configured augmentation and training, and developed the MATLAB testing script. I analyzed predicted labels and class probabilities to identify uncertain classifications and opportunities for improvement.

WHAT I LEARNED

Strengthened my understanding of transfer learning, image preprocessing, and neural network training. I learned to distinguish prediction confidence from accuracy and assess how dataset size and diversity influence classification performance.
