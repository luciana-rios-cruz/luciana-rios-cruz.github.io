Abre index.html con doble clic para revisar el sitio en tu computadora.
Todos los archivos funcionan juntos, sin instalar programas.

PARA SUBIR A GITHUB
1. Descomprime este ZIP.
2. Abre tu repositorio luciana-rios-cruz.github.io, pestaña Code.
3. Elige Add file (o el botón + junto a Code) > Upload files.
4. Arrastra TODOS los archivos .html y style.css de esta carpeta.
   Deben quedar en la raíz del repositorio, junto a README.md.
   No subas el ZIP ni una carpeta contenedora.
5. Guarda con Commit changes. El nuevo index.html reemplazará la portada anterior.
6. La actualización aparecerá en https://luciana-rios-cruz.github.io/ al terminar GitHub Pages.
